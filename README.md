# byo-oss/conventions

The rules that let BYO packages (`better-inbox`, the helpdesk, and what comes next) work as one system: one identity, one permission model, one way to run background work, one UI style.

BYO packages are libraries, not services. Your app, your database, your better-auth users and organizations. And when you outgrow one, it comes with a documented way out to the tool you're moving to.

- [SPEC.md](SPEC.md): the conventions. Part 1 is required today; Part 2 is proposed shared packages.

Community project, not affiliated with the better-auth team.
